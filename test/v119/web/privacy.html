隐私政策

我们把学习数据尽量留在你的设备上，并把麦克风、联网识别与不同发行渠道的差异说清楚。

生效：2026-09-04版本：1.1适用：网页、Android、iOS
适用范围本机数据语音购买联网与第三方你的控制ภาษาไทย

1. 适用范围与负责人

本政策适用于“萨瓦迪卡”中泰双向语言学习应用。隐私负责人是商店下载页或项目仓库所列的应用开发者。隐私、安全或删除问题可通过公开支持渠道联系；请不要在公开工单中提交录音、身份证件、电话号码或其他敏感信息。

原生商店版不提供真人语伴直连、账号、广告或跨应用跟踪。商店内购买使用 Apple / Google 结算，并由 RevenueCat 校验匿名购买权益；网页测试版与三星直装版可能保留“认识的人手动邀请”功能，本政策会分别说明。

2. 保存在设备上的数据

学习方向、场景语气、课程进度、收藏、错题、游戏成绩、同机对战昵称与最近战绩、声音包状态、引导状态和成年人确认保存在本机应用存储中。开发者没有用户账号服务器，不会把这些学习记录自动上传。

  • 应用不使用广告标识、广告 SDK、跨应用跟踪、远程画像或自建统计 SDK。
  • 应用内“导出学习数据”会生成一个不含录音的 JSON 文件，由你自行决定保存或分享。
  • “清除本机学习数据”经二次确认后删除本应用登记的学习键和可删除缓存；未导出的进度无法恢复。
  • Android 安装包明确关闭应用备份。iPhone/iPad 是否把应用沙盒纳入用户自己的加密设备备份，由 Apple 的系统备份设置控制；萨瓦迪卡不运营独立云备份。

3. 麦克风、录音与语音识别

  • 只有在你点击录音、跟读或发音评分后，应用才请求麦克风权限；系统会显示录音权限或状态提示。
  • 普通练习录音只用于当前页面即时回放和评分。应用不会把录音写入学习导出文件；退出、刷新或重新录制时会释放临时录音。
  • 本地可完成录音回放、音量/音高辅助和已内置答案比对。若你明确允许“本次联网识别”，操作系统或浏览器的语音识别服务可能把本次音频发送给其服务商处理。开发者不接收该音频，但服务商自己的政策可能适用。
  • 拒绝麦克风或联网识别后，文字课程、词库、选择题和不依赖口语的游戏仍可使用。
发音分数是练习反馈，不是考试认证、医疗判断或“母语口音”证明。

4. 商店购买与 RevenueCat

App Store / Google Play 版本提供一次性非消耗型“永久完整版”。付款、银行卡或其他支付资料由 Apple 或 Google 直接处理，萨瓦迪卡及 RevenueCat 不会获得完整银行卡信息。

  • 为了显示、授予、恢复并防止重复授予购买权益，RevenueCat 会处理随机生成的匿名 App User ID、商品标识、购买日期、购买状态、购买来源商店及相关购买历史。
  • 这些数据用于应用功能、购买状态分析、收据验证和反欺诈；传输使用加密连接。应用不主动向 RevenueCat 发送姓名、邮箱、学习记录、录音、广告标识或设备广告追踪信息。
  • 应用没有登录账号，因此开发者按匿名购买支持编号查询购买权益。该编号可从“永久完整版”页面复制；不要把它、订单号或收据贴到公开工单。
  • 购买记录会按授予权益、退款/争议处理及适用财税或平台义务所需期限保存。你可通过商店下载页所列的私密支持邮箱申请删除 RevenueCat 客户记录；Apple / Google 自身保存的交易记录和法定义务仍按其政策处理。

5. 网络、真人邀请与托管

原生商店版

不包含真人语伴直连模块。学习内容与内置语音从安装包读取；联网识别是否发生只取决于你的明确操作和设备能力。

网页测试版 / 三星直装版

认识的人可手动交换邀请码后用 WebRTC 建立点对点连接。语音只有在录制、试听并再次点击发送后才会传给对方。对方可能保存内容，应用无法代替你撤回。建立连接时双方及 STUN 基础设施可能看到网络地址；该模式没有中央消息存储、随机匹配或平台级举报系统，因此不进入原生商店版。

网页托管

公开页面由 GitHub Pages 托管。托管方可能为安全、反滥用和运行目的处理 IP 地址、请求时间、User-Agent 等访问日志；这些日志不由本应用代码读取。详情见 GitHub 隐私声明。

6. 保存期限、权限与你的选择

本机学习数据保留到你在应用内清除、清除网站数据或卸载应用。由于没有学习账号和云端进度服务器，开发者无法远程找回、查看或删除你设备上的学习记录；商店版的匿名购买权益记录是上一节所述的例外。

  • 可在系统设置中随时撤销麦克风、语音识别或网络权限。
  • 可导出学习数据后，再清除本机数据或卸载应用。
  • 网页用户可在浏览器站点设置中清除权限、缓存和本地存储。
  • 购买问题或 RevenueCat 数据删除请求请使用私密支持邮箱，并附应用内复制的匿名支持编号；不要在公开工单中提交订单或收据信息。

本应用不是专门面向儿童设计。五档场景表达均不包含攻击、羞辱或仇恨内容；家长或监护人仍应根据商店年龄分级决定是否允许未成年人使用。

7. 变更与联系

若新增账号、云同步、广告、平台真人匹配或新的数据用途，我们会先更新本政策和商店隐私披露，并在需要时重新取得同意。重大变更会更新页面顶部的生效日期。
