# 隐私说明

生效日期：2026-09-04

本说明覆盖“萨瓦迪卡”的公开网页、Android 直装版及原生商店版。便于普通用户阅读的完整中泰双语版本见 [隐私政策页面](./privacy.html)。隐私负责人是当前下载商店页或项目仓库所列的应用开发者，可通过[项目支持渠道](https://github.com/axldsg99999-ship-it/huilaishi-app/issues)联系。请勿在公开工单中提交真人录音或敏感个人信息。

## 本机保存的数据

学习方向、场景语气、课程进度、收藏、错题、游戏成绩、同机对战昵称与最近战绩、离线包状态、引导状态和成年人确认保存在设备本机。当前版本不使用账号、广告标识、广告 SDK、跨应用跟踪、远程画像或自建统计 SDK，也不会把学习记录自动上传。

应用内“导出学习数据”会下载不含麦克风录音的 JSON 副本。“清除本机学习数据”会在二次确认后删除本应用登记的学习键和可删除缓存；未导出的进度无法恢复。Android 安装包明确关闭应用备份。iPhone/iPad 是否把应用沙盒纳入用户自己的加密设备备份，由 Apple 系统设置控制；萨瓦迪卡不运营独立云备份。

## 麦克风与语音

- 只有在用户主动点击录音、跟读或发音评分后，应用才请求麦克风权限。
- 普通练习录音仅用于当前页面即时回放和辅助评分，不写入学习数据导出文件；刷新、退出或重新录制时释放临时录音。
- 本地可完成回放、音量/音高辅助和已内置答案比对。只有用户明确允许“本次联网识别”时，操作系统或浏览器才可能把本次音频交给其语音识别服务；开发者不接收该音频，服务商政策可能另行适用。
- 拒绝麦克风或联网识别后，文字课程、词库、选择题和其他不依赖口语的游戏仍可使用。

## 真人邀请房与发行渠道

原生 App Store / Google Play 商店版不包含真人语伴直连模块。

公开网页或 Android 直装测试版可能保留“认识的人手动邀请”功能。两位用户交换邀请码后用 WebRTC 直连；消息只在当前会话中处理，不进入开发者服务器。语音需录制、试听并再次点击发送后才传给对方。对方可能保存内容，应用无法替用户撤回。连接时双方及 STUN 基础设施可能看到网络地址。该模式没有中央随机匹配、中央消息存储或平台级举报系统，因此不进入原生商店版。

## 托管、保存与用户控制

公开网页由 GitHub Pages 托管。托管方可能为安全和运行目的处理 IP 地址、请求时间和浏览器信息等访问日志；应用代码不读取这些日志。详情见 GitHub 的隐私声明。

本机数据保留到用户在应用内清除、清除网站数据或卸载应用。因为没有账号和服务器用户档案，开发者无法远程找回、查看或删除设备上的学习记录。用户可在系统设置中随时撤销麦克风、语音识别或网络权限。

## 商店购买

App Store / Google Play 版本的一次性永久完整版由 Apple 或 Google 处理付款，应用不接收完整银行卡资料。RevenueCat 为授予、验证和恢复权益而处理随机匿名 App User ID、商品标识、购买日期、状态、来源商店及购买历史，用途为应用功能、购买状态分析、收据验证和反欺诈。应用不主动向 RevenueCat 发送姓名、邮箱、学习进度、录音、广告标识或跨应用追踪信息。用户可在购买页复制匿名支持编号，并通过商店页所列的私密支持邮箱申请删除 RevenueCat 客户记录；不得把支持编号、订单或收据贴到公开工单。Apple / Google 自身的交易保存与删除规则仍适用。

本应用不是专门面向儿童设计。五档场景表达均不包含攻击、羞辱或仇恨内容；监护人仍应根据商店年龄分级决定未成年人是否使用。

若以后新增账号、云同步、广告、平台真人匹配或新数据用途，项目方必须先更新本说明和商店隐私披露，并在需要时重新取得同意。
