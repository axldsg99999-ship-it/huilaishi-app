# Art provenance

## `sawadeeka-collage-burst-v1.webp`

- Created for this project with OpenAI's built-in image generation tool on 2026-08-28.
- A user-supplied image was used only as a reference for handmade collage material, stitching, torn-paper layering, and unfolding rhythm. The source image is not shipped with the app.
- The generated composition is original and deliberately excludes playing cards, text, logos, people, and Japanese motifs.
- Production processing: genuine alpha extraction with the image tool, then a mechanical resize and WebP conversion with FFmpeg (`960 × 924`, alpha preserved).
- Intended use: decorative interface texture only; it does not convey learning content or replace accessible labels.
