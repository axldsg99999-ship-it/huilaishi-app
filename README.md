# 会来事 · 中泰双向语言学习 App

面向中国人与泰国人的双向、游戏化移动语言学习原型。

核心概念：**同一句话，五种语域；你教我一句，我回你一句。**

永久 HTTPS 应用：https://axldsg99999-ship-it.github.io/huilaishi-app/

固定安装二维码见输出目录中的 `苹果安卓永久双码.png`。

## 手机上最快打开（同一个 Wi‑Fi）

1. 电脑双击 `打开手机预览.bat`。
2. 如果 Windows 防火墙询问，只在可信家庭 Wi‑Fi/个人热点中允许“专用网络”。
3. 手机和电脑连同一个 Wi‑Fi。
4. 电脑会弹出一张“双码”图：左码直接试玩，右码强制下载 Android 离线 HTML。
5. 预览期间不要关闭黑色命令窗口；按 `Ctrl+C` 可停止。

启动器会自动避开已占用端口，不会关闭其他程序。每次换 Wi‑Fi 后应重新运行，以生成当前 IP 对应的新二维码。

若手机打不开，请依次检查：两台设备是否同一 Wi‑Fi、Windows 是否允许专用网络、路由器是否开启了“访客隔离/AP 隔离”。

> 扫码下载使用临时局域网地址：电脑服务窗口关闭后就失效。要制作能长期分享给他人的永久二维码，必须先部署到固定 HTTPS 地址。

> 局域网 HTTP 地址适合立刻预览，但浏览器出于安全原因不会在这种地址上启用 PWA 安装、离线缓存和麦克风。要测试这些能力，请使用 HTTPS 部署版。

## 安装成真正的离线 App

本目录已包含 `manifest.webmanifest`、`service-worker.js` 和 192/512 图标，可直接部署到任意 HTTPS 静态网站。

- Android：用 Chrome 打开 HTTPS 地址，选择“安装应用”或点个人页里的“安装离线版到手机”。
- iPhone/iPad：用 Safari 打开 HTTPS 地址，点“分享”→“添加到主屏幕”。
- 第一次完整打开后，界面、课程、每条路线 48 张话术卡和本地情景对话会缓存到设备，之后可以断网启动。

也提供 `会来事-手机离线单文件.html`：发送到 Android 手机后可作为完全本地的应急试玩版打开。由于 iOS 对本地 HTML 和麦克风限制更严，iPhone 建议使用 HTTPS PWA。

## 离线实时对话如何工作

离线对话没有伪装成“离线大模型”，而是明确分三层：

1. **本地情景引擎**：每条路线 8 个场景、40 条精品分支、关键词匹配、NPC 即时接话、语域与风险反馈，全程零网络请求。
2. **本地语音识别**：仅当浏览器明确支持设备端 `SpeechRecognition.processLocally` 且对应中/泰语言包可用时开放。首次下载语言包需要联网；识别时不降级到云端。
3. **通用离线降级**：所有手机始终可使用快捷选句和键盘输入；HTTPS/已安装 App 还可本机录音并即时回放，录音不上传，刷新后清除。

如果设备不支持本地语音识别，界面会明确写出原因，不会偷偷调用联网识别。

## 阿来声线

- 原创声音人格：聪明、松弛、带一点坏笑的双语学习搭子。
- 中文口播：“准备好了？开口，就会来事！”
- 泰文口播：“พร้อมไหม? มาฝึกพูดให้เป็นกัน!”
- 每条路线内置开场、答对、重试、高风险与升级 5 类本地语音提示，并配两下木质弹音加上扬空气音的原创声标。
- 声音文件随 PWA 缓存，并以 Base64 嵌入 Android 单文件版；断网仍可播放。
- 本原型没有克隆任何真人；正式商用可按同一声线规范邀请中泰双语配音演员重录。

## 糖刀声线 · S1 反差音色

- S1“混人局”故意使用甜、轻、可爱的女生感声线来说高冒犯度台词，形成“声音越甜，话越冲”的记忆反差。
- 已为中泰两条路线制作主档位试听和 20 组冲突场景，共 42 段本地 MP3；中文采用温暖柔和的女声，泰语采用原生女声，以慢速、低能量和平静标点轻声演绎；新版母带轻抬辅音清晰度并控制齿音，听得更清楚但仍不凶、不怒读。
- S1 的可爱包装不会降低风险等级：界面始终标为高危，只用于听懂、避坑、影视与冲突识别。
- 没有克隆、模仿或冒充任何真人声音。

## 内容规模

- 中国人学泰语、泰国人学中文两条独立路线。
- 便利店、餐厅、打车、酒店、市场、职场、交朋友、紧急求助 8 个离线场景。
- 每条路线 48 张句卡，覆盖 S5 体面到 S1 冲突识别。
- 泰文配罗马音和中文释义；中文配拼音和泰文释义。
- 两套三题便利店剧情课、场合判断战、互助搭子、面对面传手机模式。
- 5 个离线玩法：闪电配对、听音狙击、45 秒选义、素质雷达、体面改写。
- 学习方向、默认语域、离线场景和互动进度均按路线保存在本机。

## 六级双向词汇系统

- L1 生存开口、L2 日常基础、L3 旅行社交、L4 工作生活、L5 观点表达、L6 社会文化。
- 已完成每级 500 个训练条目，共 3,000 条；两条学习方向镜像呈现，不是简单机翻界面。
- 中国人学泰语显示泰文、罗马音、中文义、泰语例句及中文翻译；泰国人学中文显示汉字、拼音、泰文义、中文例句及泰文翻译。
- 支持中文、泰文、拼音和罗马音搜索，并按人物、日常、饮食、旅行、购物、时间、工作、学习、社交、健康、紧急、文化筛选。
- 收藏、掌握、错词本和分箱复习进度按学习方向分别保存在本机。
- 10 词闯关优先抽取到期词、错词和未学词；答错会立即回到待复习队列。
- 原 1,500 条核心词保留教学复现；新增 1,500 条扩展词要求不与原词头重合，并通过 ID、字段、读音脚本、双语例句包含与分级数量校验。

## 电脑试玩

可直接双击 `index.html`。为了测试完整 PWA 离线缓存，请在本目录运行静态服务器后通过 `http://localhost` 打开；浏览器把 localhost 视为安全开发环境。

## 产品边界

- “素质档位”评价表达语域，不评价学习者人格。
- S5 是正式克制，S4 是日常礼貌，S3 是熟人随意，S2 是命令/不耐烦/讽刺，S1 是明确粗口、驱赶或人格攻击；它与词汇难度 L1–L6 是两套完全独立的轴。
- S1/S2 主要用于听懂、防坑、影视理解和冲突识别，不包装成推荐表达。
- 紧急场景优先评价信息是否完整，直接、急促不等于“低素质”。
- AI 体验搭子在界面中明确标注，不伪装成真人在线。
- 当前为高保真产品原型，正式上线前仍应由中文及泰语母语教师逐句终审，并录制真人发音。
