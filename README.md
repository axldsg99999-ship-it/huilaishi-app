# 会来事 · 中泰双向语言学习 App

面向中国人与泰国人的双向、游戏化移动语言学习应用。

核心概念：**同一句话，五种语域；你教我一句，我回你一句。**

HTTPS 应用：https://axldsg99999-ship-it.github.io/huilaishi-app/

当前仓库版本：**12.6.0 公开测试版**。正式学习区仍是 **3,000 张训练卡 = 2,875 组独立中泰词对 + 125 张复现训练卡**；另有 **1,125 组只读待审候选**，两层合计 4,000 组独立库存词对。待审候选不计入课程、测验、跟读或固定示范音。

三星签名 APK 的固定下载二维码见输出目录中的 `会来事12.6-三星APK二维码.png`；苹果 Safari 安装二维码见 `会来事12.6-苹果安装二维码.png`。

## 手机上最快打开（同一个 Wi‑Fi）

1. 电脑双击 `打开手机预览.bat`。
2. 如果 Windows 防火墙询问，只在可信家庭 Wi‑Fi/个人热点中允许“专用网络”。
3. 手机和电脑连同一个 Wi‑Fi。
4. 电脑会弹出一张“双码”图：左码直接试玩，右码强制下载 Android 离线 HTML。
5. 预览期间不要关闭黑色命令窗口；按 `Ctrl+C` 可停止。

启动器会自动避开已占用端口，不会关闭其他程序。每次换 Wi‑Fi 后应重新运行，以生成当前 IP 对应的新二维码。

若手机打不开，请依次检查：两台设备是否同一 Wi‑Fi、Windows 是否允许专用网络、路由器是否开启了“访客隔离/AP 隔离”。

> 扫码下载使用临时局域网地址：电脑服务窗口关闭后就失效。要制作能长期分享给他人的永久二维码，必须先部署到固定 HTTPS 地址。

> 局域网 HTTP 地址适合立刻预览，但浏览器出于安全原因不会在这种地址上启用 PWA 安装、离线缓存和麦克风。要测试这些能力，请使用 HTTPS 部署版。

## 安装成真正的离线 App

本目录已包含 `manifest.webmanifest`、`service-worker.js` 和 192/512 图标，可直接部署到任意 HTTPS 静态网站。

- Android：用 Chrome 打开 HTTPS 地址，选择“安装应用”或点个人页里的“安装离线版到手机”。
- Android APK：仓库内置可重复的 Capacitor 云构建；测试安装包与签名说明见 [`ANDROID_BUILD.md`](./ANDROID_BUILD.md)。APK 直接打包离线内容，不依赖旧网页缓存。
- iPhone/iPad：用 Safari 打开 HTTPS 地址，点“分享/更多”→“添加到主屏幕”→打开“作为网页 App 打开”→“添加”。应用内与下载页现提供可聚焦的逐步引导；这是现在可用的 PWA 安装方式，不是 App Store 安装包。
- 原生 iOS：Capacitor 8 工程、iOS 15 部署目标、隐私清单、权限说明、品牌启动页与固定 `macos-26` / Xcode 26.6 无签名模拟器 CI 已补齐；TestFlight/App Store 签名上传严格受 Apple secrets 与受保护 Environment 控制，详情见 [`IOS_BUILD.md`](./IOS_BUILD.md)。凭证齐全前不会提供不可用的假 IPA。
- 首次打开只缓存界面、课程、五档语域表达与本地情景对话，达到“基础离线可用”；**不会自动下载** 696 段核心运行时音频（约 23.3 MB）。用户可在个人页明确同意后开始、暂停或删除核心语音；3,000 张训练卡对应的扩展学习音也按方向和 L1–L6 自选安装。

也提供 `会来事-手机离线单文件.html`：发送到 Android 手机后可作为完全本地的应急试玩版打开。由于 iOS 对本地 HTML 和麦克风限制更严，iPhone 建议使用 HTTPS PWA。

## 离线实时对话如何工作

离线对话没有伪装成“离线大模型”，而是明确分三层：

1. **本地情景引擎**：每条路线 8 个场景、40 条精品分支、关键词匹配、NPC 即时接话、语域与风险反馈，全程零网络请求。
2. **本地语音识别**：仅当浏览器明确支持设备端 `SpeechRecognition.processLocally` 且对应中/泰语言包可用时开放。首次下载语言包需要联网；识别时不降级到云端。
3. **通用离线降级**：所有手机始终可使用快捷选句和键盘输入；HTTPS/已安装 App 还可本机录音并即时回放，录音不上传，刷新后清除。

键盘和本机转写统一使用语域安全匹配：完整句优先，S1 只有命中当前场景独有的明确粗口/攻击词才会进入识别流程，急救求助按生命安全优先；泰语正规化保留元音与声调符，不再把安全词误压成粗口片段。识别到 S1 时不会发送原句，而会显示原因并改为同场景 S4 安全回应。

如果设备不支持本地语音识别，界面会明确写出原因，不会偷偷调用联网识别。

## 跟读反馈（测试版）

- 每节发音课都可录音、回放，并显示设备转写匹配、字词完整度、流利度和语速反馈。
- V12 增加完全在设备端运行的“相对音高镜”：将固定学习示范音与用户录音的有声音段归一化后，显示两条相对升降曲线；男女声或绝对音高差不会直接决定结果。
- 音高镜由本地固定的 Pitchy 4.1.0 与 fft.js 4.0.4 提取 F0，不上传录音、不进入跟读总分，也不裁决中文或泰语词汇声调。
- 只有浏览器明确提供对应语言的本机识别包时，才标为“本地识别”；否则默认只录音回放。
- 用户可为单次练习明确允许浏览器/系统联网识别。许可用完即失效，不会静默延续到下一次。
- 结果衡量的是“设备是否听懂”，不能精确判断泰语声调、元音长短、送气或母语口音；这些项目保留给母语教师终审。
- 泰语比较会保留声调与组合元音符号，否定词和数字属于关键内容，漏掉时不会给高分。

## 真人语伴与 AI 体验

- 首页明确分为“真人语伴”和“AI 体验”，不会把预设角色伪装成在线真人。
- 当前可用的真人模式是 18+ 手动邀请房：两位认识的人交换邀请码与回答码，通过 WebRTC 直连发送文字、互改和语音留言。
- 语音先留在本机预听，只有点击发送后才传给对方；关闭、切后台、断网或切方向都会立即停止麦克风。
- 邀请码可能含网络信息，只应发给信任的人；双方需通过另一条可信渠道核对验证码。当前没有中央账号、随机匹配或平台举报受理，因此界面不会声称这些能力已上线。
- `backend/` 提供默认关闭的 Supabase 中央匹配安全骨架与 RLS/Storage/Realtime 迁移，配置真实项目、认证、审核和运营流程前不得启用。

## V12.2 三轨声音系统

- `STANDARD` 是默认学习轨：中文 Xiaoxiao、泰语 Premwadee，原始音高、自然语速、轻量响度整理；不使用升调、rubberband、asetrate 或 formant 搬移。当前资产是固定的合成语音学习示范音，不是原创真人录音，也不代表母语教师已经认证。
- `CHARACTER` 只用于 S1 风险台词的角色演绎：目标是成年女声、软、甜、清楚；当前固定资产仍是合成角色样音，界面始终标为“非标准发音、禁止跟读”，待真人配音替换。
- `NAVIGATION` 只用于按钮、方向入口与界面反馈的固定提示，不作为学习发音；它与学习句按轨严格隔离。
- 阿来开场、答对、重试、高风险与升级提示属于 UI 导航音，不作为发音示范；10 条运行时提示采用原始音高。`alai-sonic-mark.mp3` 仅为设计/声标母件，不缓存、不内嵌，也不是运行时依赖。
- 中文口播：“准备好了？开口，就会来事！”；泰文口播：“พร้อมไหม? มาฝึกพูดให้เป็นกัน!”
- 核心固定语音采用分阶段 PWA 缓存；词汇游戏只播放已内置或已完整安装的学习示范声包，缺包时明确提示，不以设备 TTS 冒充固定示范音。其他普通点读若使用系统备用声线，会在播放状态中如实标示。
- 语音元数据明确标记 `track`、用途与母语教师终审状态；本版本没有克隆、模仿或冒充任何真人。仓库尚无足以批准正式商业生成与再分发的付费层级或授权凭证；补齐并核验凭证或替换资产前，不得宣称这些声音已获正式商用批准，详见 `VOICE_ASSET_PROVENANCE.md`。

## S1 反差角色音

- S1 的声音方向是成年女声，软、甜、清楚地演绎高冒犯台词，形成记忆反差；不吼、不凶，也不以可爱包装降低风险。当前版本是合成角色样音，不代表真人声优或母语教师已经认可。
- 成年女声只是角色配音方向，不等于句中学习者的性别；泰语对话会明确提示 `ครับ / ผม`（男性常用）与 `คะ / ค่ะ`、`ดิฉัน / ฉัน`（女性用法）不能混为一谈。
- 中泰两条路线保留 42 段兼容角色音，并纳入 60 条 S1 `CHARACTER` 核心母带；全部为原始音高，不做强制升调或二次变调。
- 慢听固定为 0.88× 并保持原音高；S1 只训练听懂攻击点和选择 S4 安全回应，不提供跟读任务。
- S1 的可爱包装不会降低风险等级：界面始终标为高危，只用于听懂、避坑、影视与冲突识别。
- 没有克隆、模仿或冒充任何真人声音。

- 中国人学泰语路线已为 3,000 张训练卡及其例句、五档语域和离线对话接入中文近音；如 `สวัสดีค่ะ → 萨-瓦-迪-卡`，并始终标注“仅助记”。
- 中国人学泰语显示泰文、罗马音、中文义、泰语例句及中文翻译；泰国人学中文显示汉字、拼音、泰文义、中文例句及泰文翻译。
- 支持中文、泰文、拼音和罗马音搜索，并按人物、日常、饮食、旅行、购物、时间、工作、学习、社交、健康、紧急、文化筛选。
- 收藏、掌握、错词本和分箱复习进度按学习方向分别保存在本机。
- 10 词闯关优先抽取到期词、错词和未学词；答错会立即回到待复习队列。
- 自动门禁分别核对 3,000 张训练卡、2,875 组独立词对、125 张复现卡、每级 500 张，以及 ID、字段、读音脚本和双语例句结构；重复卡会明确标为复现训练，不冒充新增独立词。
- `lexicon-review/first-pass-125.json` 提供 125 条可追溯的补词终审候选；它们只有 OMW 2.0 单源同义集证据，第二来源、母语终审、拼音/泰语转写、例句和音频均未放行，因此全部被自动门禁阻止导入正式词库。
- `lexicon-review/expansion-candidates-1000.json` 追加 1,000 条机器筛选候选：只保留 Chinese Open WordNet、Thai WordNet 与 Princeton WordNet 在同一 PWN 3.0 synset 下各自唯一的中泰 lemma，并用官方 SemCor 标注频次做确定性排序。该对齐仍属于同一 WordNet 证据链，不算第二独立来源；`validate:vocab-inventory` 会阻止任一候选误入训练、测验、跟读或语音评分。
- 教师审核从 `lexicon-review/first-pass-125.json`（优先）和 `lexicon-review/expansion-candidates-1000.json` 开始；`vocab-review-candidates.js` 只是由构建脚本生成的只读界面索引，不可直接手改成已通过。导入正式词库前，单条候选必须补齐第二独立来源、中泰母语教师签字、拼音、泰语转写与声调、中文近音免责声明、双语例句、语域/安全审查和与文字一致的固定示范音；之后再进入对应 L1–L6 数据文件、音频清单和全套门禁。
- 扩展声音按 `学习方向 × L1–L6` 拆成 12 包，现已全部完成：覆盖 12,000 个词头/例句点读槽位，包内去重后为 11,395 段真实 MP3，总计 260,840,295 bytes（248.76 MiB）；安装时逐文件校验大小与 SHA-256，整包校验完成前不会冒充“已安装”，取消后可断点续装。
- 大声音包不进入 PWA 核心缓存，也不嵌入 Android 单文件；单文件保留 550 条核心三轨音频及其课程/角色/UI 兼容音，扩展包只在 HTTPS/PWA 中按需下载。

## 产品边界

- “素质档位”评价表达语域，不评价学习者人格。
- S5 是正式克制，S4 是日常礼貌，S3 是熟人随意，S2 是命令/不耐烦/讽刺，S1 是明确粗口、驱赶或人格攻击；它与词汇难度 L1–L6 是两套完全独立的轴。
- 普通 S2 可在明确警示下做边界对比跟说，并配一条 S4 安全改写；急救场景的明确指令按生命安全优先，不套用这条改写规则。S1 只用于听懂、防坑、影视理解和冲突识别，禁止跟读。
- 紧急场景优先评价信息是否完整，直接、急促不等于“低素质”。
- AI 体验搭子在界面中明确标注，不伪装成真人在线。
- 当前为高保真可运行版本；正式商用前仍需完成中文及泰语母语教师逐句终审。终审教师的组织、逐句签字与上线批准由项目方负责；自动 QA、设备转写与相对音高镜都不得替代教师对声调、长短音、送气和自然语感的判断。
- 当前声音均为合成资产，不是原创真人录音；商业生成与再分发凭证仍待项目方补齐和核验，在此之前不得宣称声音已获正式商用批准。
